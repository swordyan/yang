---

### 🔮 经典概念：康德的道德哲学——真正的道德，不靠结果说话

**伊曼努尔·康德（Immanuel Kant，1724—1804）** 是哲学史上影响力最大的人物之一。他一生几乎没有离开过家乡柯尼斯堡，却构建了一套彻底改变哲学方向的思想体系。

今天只聚焦他道德哲学的核心：**一个行为是否道德，不看结果，只看动机。**

---

### 🧱 两种道德观的根本分歧

先感受一下康德的对立面——**后果主义（功利主义）**：

> 一个行为是否道德，取决于它产生的后果。如果结果对最多人最有利，那就是道德的。

康德说：**不对。**

他的例子：假设你藏了一个无辜的人，杀手来问你"他在哪里？"

- 后果主义：你可以撒谎，因为撒谎的后果（救了人）比说实话（害了人）更好。
- 康德：**你不能撒谎，哪怕后果是坏的。** 因为道德不是算后果的游戏。

---

### 🧱 康德的核心工具：定言命令

康德提出了一个检验行为是否道德的"公式"，叫做**定言命令（Categorical Imperative）**：

> **"只依照你同时能够意愿其成为普遍法则的准则行动。"**

换成大白话：**在做一件事之前，先问自己——如果所有人都这样做，世界会怎样？如果那个世界是荒谬的或自我矛盾的，那这件事就是不道德的。**

---

### 📊 用例子理解定言命令

**例子：我可以在困难时撒谎借钱，明知还不上也保证会还？**

第一步：把这个行为变成"普遍法则"：
> "所有人在需要钱时都可以许下无意履行的承诺。"

第二步：这个普遍法则有意义吗？
> **没有**——如果所有人都这样做，"承诺"这个概念就失去了意义，没有人会相信任何承诺，借钱这件事本身就会崩溃。

第三步：结论：
> 这个行为是不道德的，不管我多么需要那笔钱。

---

**例子：我可以帮助遇到困难的陌生人吗？**

第一步：普遍化：
> "所有人都应该在力所能及时帮助遇到困难的陌生人。"

第二步：这个世界有意义吗？
> **有**——这个世界不会自我矛盾，甚至更好。

第三步：这个行为是道德的，甚至是义务。

---

### 🔬 进阶小窗①：目的王国——把人当目的，不当手段

康德还有另一个版本的定言命令，更直觉：

> **"永远把人（包括你自己）当作目的本身，而不只是手段。"**

这句话的含义：你不能为了达成某个目标，把另一个人纯粹当工具使用，无视他作为人的价值和尊严。

这是现代人权概念、反对奴役、反对剥削的哲学基础之一。

### 🔬 进阶小窗②：康德 vs 功利主义——经典争论

这是哲学史上最著名的道德争论之一：

**电车难题**：一辆失控的电车正冲向五个人，你可以拉一个手柄，让它转向，只撞死一个人。你拉吗？

- **功利主义**：拉！1 < 5，结果更好。
- **康德**：这要看你的动机和行为本质——你是在"利用"那一个人的死来救五个人吗？如果是，这是把一个人纯粹当手段，不道德。

这个难题至今没有标准答案，但它是理解两种道德框架最清晰的入口。

### ✨ 今日哲学金句与解析

> *"道德不是关于我们做了什么，而是关于我们为什么这样做。"——康德*

**📖 解析**：这句话的关键是"义务"与"爱好"的区分。一个商人童叟无欺，可能是因为诚实，也可能只是因为这样生意更好做。康德说：后者不算道德行为——它只是符合道德的行为，动机是私利，不是义务。真正的道德行为，是你知道这件事是对的，就算对你无利甚至有害，你仍然去做。这个要求很高，但也是道德最纯粹的形式。

### 📌 今日主题：计算机如何存储图片？——像素与 RGB

### 💡 先建立直觉：马赛克游戏

你有没有近距离看过一张低分辨率的图片——那种一格一格的感觉？

那每一个"格子"就是一个**像素（Pixel，图像元素）**。

一张图片，本质上就是**一个巨大的像素网格**，每个像素存储一个颜色信息。计算机把这些像素一个一个存下来，显示时再一个一个画出来。

---

### 🧱 颜色怎么表示？——RGB 模型

人眼有三种感光细胞，分别对**红（Red）、绿（Green）、蓝（Blue）**敏感。

计算机用同样的思路：**任何颜色 = 红色分量 + 绿色分量 + 蓝色分量的混合**。

每个分量的范围是 **0～255**（用 8 位二进制存储）：
- 0 = 完全没有这个颜色
- 255 = 这个颜色最强

---

### 📊 常见颜色的 RGB 值

| 颜色 | R | G | B | 十六进制 |
|---|---|---|---|---|
| 纯红 | 255 | 0 | 0 | #FF0000 |
| 纯绿 | 0 | 255 | 0 | #00FF00 |
| 纯蓝 | 0 | 0 | 255 | #0000FF |
| 白色 | 255 | 255 | 255 | #FFFFFF |
| 黑色 | 0 | 0 | 0 | #000000 |
| 黄色 | 255 | 255 | 0 | #FFFF00 |
| 橙色 | 255 | 165 | 0 | #FFA500 |
| 微信绿 | 7 | 193 | 96 | #07C160 |

> 🔑 **十六进制颜色码**：设计师常用的 `#FF0000` 就是把 R、G、B 三个数各用两位十六进制表示后拼起来。`FF` = 255，`00` = 0。

---

### 🧱 一张图片有多大？

**例子：一张 1920×1080 的全高清图片（1080p）**

```
像素总数 = 1920 × 1080 = 2,073,600 个像素（约207万像素）

每个像素 = RGB 三个通道 × 每通道 8 位 = 24 位 = 3 字节

原始大小 = 2,073,600 × 3 = 6,220,800 字节 ≈ 6 MB
```

一张未压缩的 1080p 图片大约 6MB。

**但你手机里的照片通常只有 2～4MB，为什么？**

因为用了 **JPEG 压缩**——通过丢弃人眼不敏感的细节，在几乎不影响观感的前提下大幅减小文件体积。

---

### 🔬 进阶小窗①：PNG vs JPEG vs WebP

| 格式 | 压缩方式 | 特点 | 适用场景 |
|---|---|---|---|
| BMP | 无压缩 | 最大、最清晰 | 原始存储 |
| PNG | 无损压缩 | 不丢细节，支持透明 | 图标、截图、带透明背景的图 |
| JPEG | 有损压缩 | 文件小，会损失细节 | 照片、背景图 |
| WebP | 有损+无损 | 比 JPEG 小 30%，比 PNG 小 26% | 网页图片（Google 推出） |
| SVG | 矢量（非像素） | 任意缩放不失真 | Logo、图标、插图 |

### 🔬 进阶小窗②：透明度——第四个通道 Alpha

除了 RGB，很多图片格式（PNG）还有第四个通道：**Alpha（透明度）**。

- Alpha = 255：完全不透明
- Alpha = 0：完全透明
- Alpha = 128：半透明

这就是为什么 PNG 的 Logo 放在任何背景上都没有白边——它的背景是透明的（Alpha = 0），而 JPEG 没有透明通道，背景永远是白色。

### 🔬 进阶小窗③：分辨率 vs 像素密度

- **分辨率**：图片的像素总数（如 1920×1080）
- **PPI（每英寸像素数）**：同样的像素，印在大纸上看起来模糊，印在小屏幕上看起来清晰

iPhone 的屏幕 PPI 达到 460，人眼在正常距离下已无法分辨单个像素——这就是 Apple 所说的"视网膜屏幕"的含义。

### ⚡ 实用技巧

- **网页用图**：优先用 WebP，不支持的浏览器降级用 JPEG/PNG
- **Logo 和图标**：用 SVG（矢量）或 PNG（有透明通道）
- **查看图片的 RGB 值**：Mac 用"数码测色计"App，Windows 用画图的"颜色拾取器"
- **压缩图片**：[squoosh.app](https://squoosh.app) 是 Google 出的免费在线图片压缩工具，效果极好

### 📌 今日主题：方程——数学的"侦探游戏"

### 💡 从一个谜题开始

> "我想了一个数，把它乘以 3，再加上 5，结果是 20。这个数是多少？"

你可能凭直觉就算出来是 5。但你是怎么做到的？

你实际上在解一道**方程**：

```
3x + 5 = 20
```

方程是一种**含有未知数的等式**，我们的任务是找到让等式成立的那个未知数的值。

---

### 🧱 什么是方程？

**等式**：两边相等的数学表达式。

```
3 + 5 = 8      ← 这是等式（没有未知数，直接成立）
3x + 5 = 20   ← 这是方程（含有未知数 x，需要求解）
```

**方程的核心规则：等式两边做同样的操作，等式仍然成立。**

就像天平：左右两边重量相等，如果两边同时加减同样的重物，天平仍然平衡。

---

### 🧱 解方程的步骤：一步步"孤立"未知数

**目标**：把 x 单独留在等式一边，另一边只有数字。

**例题：解 `3x + 5 = 20`**

```
第1步：两边同时减去 5
  3x + 5 - 5 = 20 - 5
  3x = 15

第2步：两边同时除以 3
  3x ÷ 3 = 15 ÷ 3
  x = 5  ✅
```

**验证（代入检查）**：
```
3 × 5 + 5 = 15 + 5 = 20  ✓
```

---

### 📊 多做几道，建立感觉

**例题 1：`x + 7 = 12`**
```
x + 7 - 7 = 12 - 7
x = 5
```

**例题 2：`2x = 14`**
```
2x ÷ 2 = 14 ÷ 2
x = 7
```

**例题 3：`x/3 = 4`**
```
x/3 × 3 = 4 × 3
x = 12
```

**例题 4：`5x - 3 = 17`**
```
5x - 3 + 3 = 17 + 3
5x = 20
5x ÷ 5 = 20 ÷ 5
x = 4
```

---

### 🧱 方程 vs 函数：有什么区别？

| | 函数 | 方程 |
|---|---|---|
| 形式 | `f(x) = 2x + 1` | `2x + 1 = 7` |
| 目的 | 描述 x 和 f(x) 之间的关系 | 找到满足等式的 x 值 |
| x | 可以是任意值 | 有特定的解 |
| 答案 | 一个规则（表达式） | 一个（或几个）数字 |

> 🔑 **联系**：方程实际上是在问"当函数 f(x) 等于某个值时，x 是多少？"
>
> `2x + 1 = 7` 就是在问：函数 `f(x) = 2x + 1` 在哪个 x 处等于 7？

---

### 🔬 进阶小窗：方程在计算机中无处不在

- **游戏物理引擎**：子弹飞行轨迹 = 解运动方程
- **机器学习训练**：找到让损失函数最小的参数 = 解（非常复杂的）方程组
- **密码学**：RSA 加密的安全性依赖于某个方程的解"极难找到"
- **搜索排名**：Google PageRank 算法 = 解一个超大型线性方程组

### 📌 今日主题：二分查找——每次消灭一半的可能性

### 💡 前提条件

二分查找有一个**必要条件**：**数据必须是有序的（已经排好序的）**。

这很合理——就像查字典，因为单词是按字母顺序排的，你才能"翻到中间，判断往前还是往后"。如果字典是随机顺序，你只能一页一页翻。

---

### 🧱 完整步骤演示

**问题**：在有序数组 `[1, 3, 5, 7, 9, 11, 13, 15]` 中，查找数字 `7`。

数组共 8 个元素，位置编号 0～7：

```
位置：  0   1   2   3   4   5   6   7
数据：  1   3   5   7   9  11  13  15
```

---

**第 1 步：设定左右边界**

```
左边界 = 0（第一个元素）
右边界 = 7（最后一个元素）
```

---

**第 2 步：找中间位置**

```
中间位置 = (0 + 7) ÷ 2 = 3（取整）
中间的数 = 数组[3] = 7
```

**比较**：`7 == 7`，找到了！✅

这道题运气好，第一次就找到了。我们再来一道没这么顺的：

---

**换一个目标：查找数字 `11`**

**第 1 步：初始状态**
```
左 = 0，右 = 7
位置：  0   1   2   3   4   5   6   7
数据：  1   3   5   7   9  11  13  15
        ↑                           ↑
       左                          右
```

**第 2 步：中间位置 = (0+7)÷2 = 3，数组[3] = 7**
```
7 < 11，说明 11 在右半部分
→ 左边界移到 3+1 = 4，扔掉左半部分
```

```
位置：  0   1   2   3   4   5   6   7
数据：  1   3   5   7   9  11  13  15
                        ↑           ↑
                       左          右
```

**第 3 步：中间位置 = (4+7)÷2 = 5，数组[5] = 11**
```
11 == 11，找到了！✅  共用了 3 步。
```

---

**再来一道：查找数字 `6`（不存在的数）**

```
第1步：左=0，右=7，中间=3，数组[3]=7。7 > 6，右边界=2。
第2步：左=0，右=2，中间=1，数组[1]=3。3 < 6，左边界=2。
第3步：左=2，右=2，中间=2，数组[2]=5。5 < 6，左边界=3。
第4步：左=3 > 右=2，左边界超过了右边界 → 数组中不存在 6。
```

---

### 📊 二分查找 vs 逐个查找

| 数组大小 | 逐个查找（最坏） | 二分查找（最坏） |
|---|---|---|
| 8 | 8 步 | 3 步 |
| 100 | 100 步 | 7 步 |
| 1,000 | 1,000 步 | 10 步 |
| 1,000,000 | 1,000,000 步 | 20 步 |
| 10亿 | 10亿步 | 30 步 |

> 🔑 **10 亿个数里找一个，最多只需要 30 步！** 这就是 O(log n) 的威力。

### 🔬 进阶小窗①：二分查找的代码实现（Python）

```python
def binary_search(arr, target):
    left = 0
    right = len(arr) - 1

    while left <= right:
        mid = (left + right) // 2   # 找中间位置

        if arr[mid] == target:
            return mid               # 找到了，返回位置
        elif arr[mid] < target:
            left = mid + 1           # 目标在右半，移动左边界
        else:
            right = mid - 1          # 目标在左半，移动右边界

    return -1                        # 没找到，返回 -1

# 测试
arr = [1, 3, 5, 7, 9, 11, 13, 15]
print(binary_search(arr, 11))   # 输出：5（位置5）
print(binary_search(arr, 6))    # 输出：-1（不存在）
```

### 🔬 进阶小窗②：二分查找的应用场景

- **数据库索引**：数据库对某列建索引后，查找某个值用的就是类似二分查找的 B 树结构
- **Git bisect**：找到引入 Bug 的那个提交——在提交历史里做二分查找，每次测试中间版本
- **猜数字游戏**：猜 1～100 之间的数，每次猜中间值，最多 7 次必中——这就是二分查找

### 📌 今日主题：栈——叠盘子的艺术

### 💡 生活里的栈

想象餐厅洗碗机旁的一摞盘子：

- 洗好一个盘子，**放在最上面**
- 服务员取盘子，**从最上面取**
- **最后放上去的，最先被取走**

这就是**栈（Stack）** 的核心规则：**后进先出（LIFO，Last In First Out）**。

栈就像一个只开口在顶端的桶：只能从顶端放入，只能从顶端取出。

---

### 🧱 栈的三个基本操作

**① Push（压栈）**：把一个元素放到栈顶

```
初始状态（空栈）：
[ ]

Push(5)：
[5]  ← 栈顶

Push(12)：
[12] ← 栈顶
[5]

Push(3)：
[3]  ← 栈顶
[12]
[5]
```

**② Pop（弹栈）**：取出栈顶元素

```
当前状态：        Pop() 之后：
[3]  ← 栈顶      取出 3
[12]            [12] ← 栈顶
[5]             [5]
```

**③ Peek / Top（查看栈顶）**：只看栈顶元素，不取出

```
当前状态：
[3]  ← Peek() 返回 3，但不取出
[12]
[5]
```

---

### 🧱 用数组实现栈（最简单的方式）

我们可以用数组来模拟栈的行为，只是约定只操作数组的末尾：

```
用数组 [5, 12, 3] 表示栈，最右边是栈顶

Push(8)：在末尾加入 → [5, 12, 3, 8]
Pop()：取出末尾  → [5, 12, 3]，返回 8
Peek()：看末尾  → 返回 3，数组不变
```

所有操作都在数组末尾，时间复杂度 **O(1)**。

### 📊 栈的完整操作演示

**问题：依次 Push(1), Push(2), Push(3), Pop(), Push(4), Pop(), Pop()**

```
操作         栈的状态         返回值
Push(1)     [1]             -
Push(2)     [1, 2]          -
Push(3)     [1, 2, 3]       -
Pop()       [1, 2]          3
Push(4)     [1, 2, 4]       -
Pop()       [1, 2]          4
Pop()       [1]             2
```

### 🔬 进阶小窗①：栈的经典应用——括号匹配

**问题**：给定一个字符串，判断括号是否正确配对。

比如：`"(()())"` 是正确的，`"(()("` 是错误的（少了右括号）。

**用栈解决**：

```
遇到左括号 ( → 压入栈
遇到右括号 ) → 弹出一个左括号（配对）
                如果栈是空的，说明右括号多了 → 错误

最后检查：如果栈不空，说明左括号多了 → 错误
          如果栈空，全部配对 → 正确
```

**演示 `"(()())"` ：**

```
( → 栈：[(]
( → 栈：[(, (]
) → 弹出 ( → 栈：[(]
( → 栈：[(, (]
) → 弹出 ( → 栈：[(]
) → 弹出 ( → 栈：[]（空了）

最后栈为空 → 括号正确 ✅
```

### 🔬 进阶小窗②：函数调用栈——栈在操作系统里

每次你在程序里调用一个函数，操作系统都会在**调用栈**上压入一个记录（栈帧），包含：
- 这个函数的局部变量
- 函数结束后要返回的地址

函数结束时，它的栈帧被弹出，回到上一个函数继续执行。

这就是为什么**函数调用是嵌套的**（像盘子一样叠起来），也是为什么递归太深会报 **"Stack Overflow"**（栈被压满了）。

### 🔬 进阶小窗③：撤销功能（Ctrl+Z）

文本编辑器的撤销功能，就是用栈实现的：

- 每次操作 → Push 到撤销栈
- 按 Ctrl+Z → Pop 出最近的操作，执行反向操作
- 按 Ctrl+Y（重做）→ 把撤销的操作再 Push 到重做栈

你每天用的撤销功能，背后就是一个栈。

### 📌 今日主题：场景描写——细节是小说的呼吸

### 💡 描写 vs 叙述：两种不同的时间感

**叙述（Narration）**：快速推进，告诉读者发生了什么。
> "三年过去了，她终于回到了这个城市。"

**描写（Description）**：放慢时间，让读者感受此刻。
> "那家便利店还在，就在地铁出口左边第三个门面。橙色的招牌在傍晚的光里显得有些旧了，但她认出来了，一眼就认出来了。"

两者都需要，但新手往往过度叙述、描写不足。读者需要具体的细节才能"进入"故事。

---

### 🧱 好的描写有什么特征？

**① 具体，不抽象**

❌ "房间里很乱"
✅ "地板上有三件没折的衬衫，一只鞋，和两个还没拆的快递盒"

❌ "她的母亲看起来老了很多"
✅ "她母亲的头发全白了，连鬓角的那一小撮也白了——上次见面时那里还是黑的"

**② 有选择性，不是什么都写**

好的描写不是"把眼睛看到的一切都写进去"，而是**选择最能说明问题的细节**。

一个房间，你写什么细节，就在暗示读者"这个细节重要"。

契诃夫的名言：**"如果第一幕里墙上挂着一支枪，那它必须在后面开枪。"**

**③ 让细节工作**

最好的细节同时完成多件事：交代环境 + 刻画人物性格 + 推进情节。

> "她把咖啡杯推到桌子边缘，又把它拉回来，推过去，再拉回来。"

这一个细节同时说明了：她在等什么，她焦虑，她犹豫，咖啡可能凉了——一石四鸟。

---

### 🔬 进阶小窗①：五感描写——不要只用眼睛

新手写描写，90% 是视觉描写。但好的场景会调动全部感官：

- **视觉**：颜色、形状、光线、动作
- **听觉**：声音的远近、节奏、忽然的静
- **嗅觉**：气味往往是最能唤起记忆的感官
- **触觉**：冷暖、质感、重量、痛感
- **味觉**：最少用，但用好了极其有力

**练习**：描写一个你熟悉的地方，每个感官至少用一个细节。

### 🔬 进阶小窗②：描写中的视角

描写永远是"某人眼中"的描写，不是客观记录。

同一个场景，不同的人物看到的"细节"完全不同：
- 厨师走进餐厅，第一眼看到的是厨房
- 建筑师走进餐厅，第一眼看到的是空间布局
- 失恋的人走进餐厅，第一眼看到的可能是角落里的那对情侣

**让你的描写带有人物的视角和情绪**，这是描写从"景色描写"变成"人物塑造"的关键一步。

### 📌 今日主题：教育社会学——学校不只是传授知识的地方

### 💡 一个让人不舒服的问题

你上学时，除了数学、语文，你还"学"到了什么？

- 准时到达、坐在固定位置、等待被叫到发言
- 评分排名、竞争、接受权威的评价
- 哪些知识重要、哪些不重要

社会学家认为：**学校除了传授知识，还在传授一套关于"社会如何运作"的隐性课程。**

---

### 🧱 显性课程 vs 隐性课程

**显性课程（Explicit Curriculum）**：公开教授的内容——数学、语言、科学、历史……

**隐性课程（Hidden Curriculum）**：在学校结构和日常运作中无意传递的价值观和行为规范：

- **守时与服从**：上课铃响必须坐好，没有商量余地
- **竞争与排名**：成绩排名让学生习得"人有高下之分"
- **知识的权威性**：老师说的就是对的，质疑是不礼貌的
- **阶层期待**：不同学校的学生，接受到对"未来"隐性的不同期待

---

### 🔬 进阶小窗①：鲍尔斯与金蒂斯——对应原理

美国社会学家鲍尔斯（Bowles）和金蒂斯（Gintis）在1976年提出**对应原理（Correspondence Principle）**：

学校的内部组织结构，与资本主义工厂的组织结构惊人地对应：

| 学校 | 工厂 |
|---|---|
| 学生服从老师 | 工人服从管理层 |
| 成绩分数 | 工资薪酬 |
| 铃声控制时间 | 打卡上下班 |
| 不同轨道（普通/重点）| 不同岗位（蓝领/白领） |

他们的结论：学校不是在促进社会流动，而是在**再生产**（reproduce）现有的阶级结构——让工人阶级的孩子学会当工人，让中产阶级的孩子学会当管理者。

### 🔬 进阶小窗②：布尔迪亚的文化资本理论（教育版）

布尔迪亚指出：学校表面上用统一的标准评价所有学生，但实际上这套标准是**中产/上层阶级文化的产物**。

中产家庭的孩子，在家就已经积累了学校看重的"文化资本"（语言习惯、阅读兴趣、文化活动）；工人阶级的孩子进入学校，要先"学会"这套文化语言，才能开始学内容。

这种"起跑线"上的差距，被学校的统一评价掩盖了，于是阶级差异被重新包装成了"个人能力差异"。

### 🔬 进阶小窗③：中国的高考与社会流动

高考制度曾经是打破家庭背景、促进阶层流动的最有效工具之一（尤其在1977年恢复高考后）。

但近年研究显示：
- 名校录取中，城市生源比例持续高于农村
- 高考辅导、课外培训的费用日益高涨，成为新的筛选机制
- 来自不同背景家庭的孩子，进入同一所大学后，在社会网络、实习机会上仍然差距显著

**教育系统能打开一扇门，但敲门的方式仍然有利于资源更多的家庭。** 这不是个人的道德问题，而是结构性的现实。

### 📌 今日主题：应收账款与坏账——账面上的钱不一定是真的钱

### 💡 应收账款是什么？

你的公司给客户提供了服务，开了发票，但客户还没付钱。

这笔"已经赚到但还没收到"的钱，就是**应收账款（Accounts Receivable）**。

```
做了服务，开票5万：
  借：应收账款  5万     （资产增加）
  贷：收入      5万     （收入确认）

客户付款时：
  借：银行存款  5万     （资产增加）
  贷：应收账款  5万     （应收账款清零）
```

应收账款是资产，但它还不是现金——如果客户最终不付，就变成了损失。

---

### 🧱 坏账：收不回来的钱

如果某笔应收账款大概率收不回来了，会计需要**计提坏账准备**：

**方法：备抵法（最常用）**

不直接从应收账款里减，而是建立一个"备抵"科目来反映可能的损失。

```
估计有 1 万元的应收账款收不回来：

  借：信用减值损失  1万    （费用增加，利润减少）
  贷：坏账准备      1万    （应收账款的备抵科目）

资产负债表展示：
  应收账款          10万
  减：坏账准备      -1万
  应收账款净额      9万
```

---

### 📊 坏账准备的估计方法

| 方法 | 说明 |
|---|---|
| 账龄分析法 | 按应收账款拖欠时间长短，分别设不同坏账率（拖欠越久，坏账率越高） |
| 销售百分比法 | 按当期销售额的固定比例（如 1%）计提坏账 |
| 个别认定法 | 针对每笔应收账款单独判断是否可能坏账 |

**账龄分析法示例：**

| 账龄 | 金额 | 坏账率 | 预计坏账 |
|---|---|---|---|
| 1个月以内 | 50万 | 1% | 0.5万 |
| 1～3个月 | 20万 | 5% | 1万 |
| 3～6个月 | 10万 | 20% | 2万 |
| 6个月以上 | 5万 | 50% | 2.5万 |
| **合计** | **85万** | | **6万** |

---

### 🔬 进阶小窗①：坏账实际发生时怎么记？

当某笔应收账款确认真的收不回来了：

```
确认坏账（已有备抵 1 万）：
  借：坏账准备  1万
  贷：应收账款  1万
（不影响利润，因为之前已经计提过损失了）
```

如果之后对方又把钱还回来了：
```
恢复应收账款：
  借：应收账款  1万
  贷：坏账准备  1万

收到现金：
  借：银行存款  1万
  贷：应收账款  1万
```

### 🔬 进阶小窗②：应收账款管理的商业意义

应收账款占比过高，是财务健康的警示信号：

- **天数分析**：`应收账款周转天数 = 应收账款 ÷ 日均收入`，天数越高，说明钱被客户"占用"越久
- **集中度风险**：如果某一个大客户欠了大量应收账款，一旦对方出问题，影响巨大
- **真实现金流**：分析公司时，要对比"利润"和"经营活动现金流"——如果利润高但现金流差，可能是应收账款大量增加造成的虚假繁荣

## 📈 板块八：经济学

> **上期回顾**：供给与需求——均衡价格是供需曲线的交点，价格管制会产生意外后果。
> **今日衔接**：均衡价格下，买卖双方都从交易中获益——这个"获益"叫消费者剩余和生产者剩余，是衡量市场效率的工具。

**📍 体系定位：** 微观经济学 → **【消费者剩余与生产者剩余——交易创造了多少价值？ ← 第 5 期】**

---

### 📌 今日主题：消费者剩余与生产者剩余——交易为什么让双方都受益？

### 💡 一个直觉起点

你口渴极了，愿意花最多 20 元买一瓶水。实际上水只卖 3 元。

你付了 3 元，但你"愿意付"20 元——你省下了 17 元的"心理价值"。

这 17 元就是你的**消费者剩余（Consumer Surplus）**。

---

### 🧱 消费者剩余

**消费者剩余 = 愿意支付的最高价格 - 实际支付的价格**

**例子**：

| 买家 | 愿意付的最高价 | 实际价格 | 消费者剩余 |
|---|---|---|---|
| 小明（很口渴） | 20元 | 3元 | 17元 |
| 小红（有点渴） | 6元 | 3元 | 3元 |
| 小李（不太渴） | 3元 | 3元 | 0元 |
| 小王（不渴） | 1元 | 3元 | 不买（低于价格） |

**市场总消费者剩余 = 17 + 3 + 0 = 20 元**

---

### 🧱 生产者剩余

**生产者剩余 = 实际售价 - 愿意接受的最低价格（成本）**

**例子**：

| 卖家 | 生产成本（愿意接受的最低价） | 实际价格 | 生产者剩余 |
|---|---|---|---|
| 工厂A（效率高） | 1元 | 3元 | 2元 |
| 工厂B（效率中） | 2元 | 3元 | 1元 |
| 工厂C（效率低） | 3元 | 3元 | 0元 |
| 工厂D（太贵） | 5元 | 3元 | 不卖（低于成本） |

**市场总生产者剩余 = 2 + 1 + 0 = 3 元**

---

### 🧱 总剩余：市场创造的总价值

**总剩余（Total Surplus）= 消费者剩余 + 生产者剩余**

在竞争市场的均衡状态下，总剩余是**最大化**的——这就是为什么经济学家认为自由竞争市场是有效率的。

任何偏离均衡的干预（价格管制、税收、垄断），都会减少总剩余，产生**无谓损失（Deadweight Loss）**——这部分价值被彻底消灭了，没有任何人得到。

---

### 🔬 进阶小窗①：税收的无谓损失

政府对每瓶水征收 2 元的税：

- 有些本来会发生的交易（买家愿付4元，卖家愿接受2.5元，本来能成交）因为加税后价格变成5元而无法成交
- 这些本来能创造的价值就消失了——这就是税收的无谓损失

> 🔑 **注意**：这不是说税收是坏的，而是说税收有效率成本。政府用税收提供的公共品（道路、教育、国防）可能值得这个成本——这是政策讨论的核心权衡。

### 🔬 进阶小窗②：垄断与消费者剩余

垄断者可以把价格定得高于均衡价格，把消费者剩余的一部分"转移"到自己的口袋里。但同时，由于价格过高，一些愿意在均衡价格下购买的消费者选择不买，导致总剩余减少。

这就是反垄断法的经济学理由：垄断减少了市场创造的总价值。

### ② 历史与文明 · 《叫魂：1768年中国妖术大恐慌》

**作者**：孔飞力（Philip Kuhn）　**豆瓣评分**：9.1　`/ 清史 / 社会史 / 政治文化`

**为什么读**：与本期社会学（教育与权力结构）形成深度呼应。孔飞力通过一场1768年的"叫魂恐慌"，解剖清朝的官僚体制、皇权运作与民间社会的复杂关系，是用微观事件剖析宏观权力结构的经典案例。

**内容概要**：1768年，中国爆发了一场关于"剪辫妖术"的大恐慌。孔飞力通过这个事件，展示了乾隆皇帝如何利用恐慌打压地方官僚、民间社会如何借恐慌解决私人积怨、以及专制体制内信息传递的系统性失真。

**如何阅读**：故事性极强，可以当悬疑小说读。建议连续读完，中途不要断。读完对中国历史的理解会提升一个维度。

> *"在中国的专制体制下，皇帝的信息来源本身就是政治斗争的产物。"*

### ③ 商业与心理 · 《非理性繁荣》

**作者**：罗伯特·席勒　**豆瓣评分**：8.5　`/ 行为金融学 / 市场泡沫 / 投资心理`

**为什么读**：与本期经济学（消费者剩余与市场效率）形成对话——标准经济学假设市场是理性的，席勒（诺贝尔奖得主）用大量数据证明市场经常不理性，泡沫是人类心理的必然产物。

**内容概要**：2000年互联网泡沫、2007年房地产泡沫，席勒在泡沫破裂前都曾预警。这本书解释了"为什么理性的个体会制造集体非理性的市场泡沫"，涉及媒体叙事、群体心理、自然实验等。

**如何阅读**：第一部分（结构性因素）是精华，建议精读。其余章节可按兴趣选读。

> *"股市并非一台精确称量价值的机器，它更像一台投票机——记录的是人气，而非价值。"*

### ④ 写作与表达 · 《文心》

**作者**：夏丏尊、叶圣陶　**豆瓣评分**：9.0　`/ 中文写作 / 语文教育 / 经典`

**为什么读**：与本期文学（场景描写）完美衔接。这是中文写作启蒙的经典，用故事的形式讲解写作技法，没有任何生硬的规则，读起来像小说。

**内容概要**：用一个初中生"大文"一年的求学经历，把32个写作和语文知识点用故事包裹起来讲解。涉及描写、记叙、抒情、语感、修辞、段落结构……是中文写作者最值得反复阅读的书之一。

**如何阅读**：当小说读，一气读完。读完再回头选感兴趣的章节细读，找到自己写作最薄弱的地方重点研究。

> *"读书不能只是囫囵吞枣，要咬文嚼字，才能把书里的东西化为自己的。"*

### ⑤ 摄影与审美 · 《决定性瞬间》

**作者**：亨利·卡蒂埃-布列松　**豆瓣评分**：9.2　`/ 摄影理论 / 人文摄影 / 大师原著`

**为什么读**：与本期摄影（场景与瞬间捕捉）直接对应。这是布列松唯一的亲笔摄影理论著作，是"决定性瞬间"理论的第一手来源，配有他最重要的摄影作品，薄薄一册，字字珠玑。

**内容概要**：布列松用极简练的语言阐述了自己的摄影哲学：好的照片，是在某个特定瞬间，形式与内容完美重合。这个瞬间稍纵即逝，摄影师必须用眼睛和心同时工作，等待它的降临。

**如何阅读**：先看作品，再读文字。文字部分不长，可以反复阅读，每读一遍都会有新的理解。建议在拍了一批照片之后读，对照反思。

> *"摄影，是在一秒的几分之一里，同时认知到事件的重要性和能够精确表达它的形式。"*

## 🎨 板块十：写作与摄影 · 每日一练

### ✍️ 写作灵感

#### 今日主题：写一个"物件"

**练习题**：选一个你身边普通的物件（一把旧伞、一个茶杯、一双鞋），用 150～200 字描写它——但不是直接描写这个物件本身，而是通过描写它，透露出**一个人的故事或状态**。

**要求**：
- 只写物件的细节（外观、位置、状态）
- 不写任何关于"主人"的直接信息
- 让读者通过物件，自己猜测那个人是谁、发生了什么

---

> 💡 **今日技巧：物件是情感的容器**
>
> 海明威最出名的六字小说：
> **"For sale: baby shoes, never worn."**（出售：婴儿鞋，从未穿过。）
>
> 没有人物，没有事件，只有一个物件和它的状态——但所有人都感受到了那个故事。
>
> **物件不只是道具，它承载着使用它的人的痕迹、故事、情感。** 选对物件，写好细节，比写一千字心理描写更有力量。

---

### 📷 摄影眼训练

#### 今日任务：拍一张"静物的表情"

找一个人造物件（杯子、椅子、钥匙、灯），把它放在某个特定的环境里，拍出它的"表情"或"情绪"。

**例子**：
- 一把落灰的椅子 → 孤独感
- 一个摔碎的杯子 → 愤怒或意外
- 一把开着的锁 → 期待或开放
- 一盏熄灭的灯 → 结束感

**要求**：用光线、背景和角度来强化你想传达的"情绪"，不要用文字说明。

---

#### 🎯 今日构图重点：低角度与高角度

**低角度（仰拍）**：相机低于主体，向上拍。
- 让主体显得高大、有力量、甚至有压迫感
- 天空成为背景，干净简洁

**高角度（俯拍）**：相机高于主体，向下拍。
- 让主体显得弱小、脆弱
- 可以展示空间布局（餐桌、街道全貌）

**今日练习**：选同一个物件，分别用低角度和高角度各拍一张，感受两张照片传达的情感完全不同。
