## 🧘 板块零：哲思

> **上期回顾**：自由意志论——我的选择，真的是"我的"吗？萨特说人被"判决"为自由。
> **今日衔接**：既然自由意志存在争议，那人生有没有意义？如果没有，我们怎么活？

---

### 🔮 经典概念：存在主义与荒诞哲学——意义是找到的还是创造的？

你有没有某个瞬间突然觉得：我在做的这些事，到底有什么意义？

这不是矫情，这是一个真实的哲学问题，而且有人用一生来认真回答它。

---

**① 存在主义（Existentialism）——萨特**

核心命题：**"存在先于本质。"**

普通的东西先有本质再有存在：锤子被设计出来是为了钉钉子，先有"锤子是什么"，才有这把锤子。

但人不一样——人先"被扔进这个世界"，然后才通过自己的选择定义自己是谁。没有上帝提前设计好你是什么，没有命运规定你该做什么。你完全自由，也完全负责。

**意义不是找到的，是创造的。**

---

**② 荒诞哲学（Absurdism）——加缪**

加缪往前走了一步，他说：

- 人天生渴望意义。
- 但宇宙对此沉默，它根本不在乎。
- 这种渴望与沉默之间的撞击，就是**荒诞（The Absurd）**。

面对荒诞，人有三条路：
1. **肉体自杀**——加缪认为这是逃避，不可取。
2. **哲学自杀**——用宗教或某种意识形态强行给世界装上意义，骗自己。加缪也反对。
3. **反抗**——清醒地承认荒诞，同时选择继续活，并活得充分。这才是加缪的答案。

> *"我们必须想象西西弗斯是幸福的。"*
>
> 西西弗斯被神惩罚，永远推石头上山，石头永远滚落。这件事本身毫无意义——但加缪说，正是在推石头的过程中，西西弗斯拥有了属于自己的生命。

---

**③ 虚无主义（Nihilism）——尼采**

尼采的立场经常被误解：他不是说"人生没意义，躺平吧"，他说的是：

**上帝已死**（西方的价值体系崩塌了），旧的意义没了，但这是一个危机，也是一个机会——人类需要自己创造新的价值，而不是躺在虚无里腐烂。

尼采提出**超人（Übermensch）**：一种能在没有外部意义的情况下，自己为自己立法的人。

---

> 💡 **今天的实用角度**：
>
> 这三位思想家给了我们三种面对"意义感缺失"的姿态：
> - **萨特**：你永远在选择，你就是你的选择之总和，别逃避这个责任。
> - **加缪**：承认生活有时很荒诞，但不需要因此崩溃——反抗荒诞本身就是意义。
> - **尼采**：旧的价值崩了不可怕，可怕的是不敢建立新的。
>
> 下次你感到"意义感缺失"时，不一定是哪里出了问题——可能只是你正在经历一次真实的哲学时刻。

## 💻 板块一：计算机科学

> **上期回顾**：ASCII 编码——给每个字符一个数字编号，字母"A"= 65 = 二进制 `0100 0001`。
> **今日衔接**：我们知道了正整数怎么用二进制表示。那负数呢？计算机怎么表示"-5"？

**📍 体系定位：** 计算机底层原理 → 信息的表示 → 二进制 → ASCII → **【负数的表示：补码 ← 第 3 期】**

---

### 📌 今日主题：计算机怎么表示负数？——补码的天才设计

### 💡 先想一个问题

我们用 8 位二进制能表示 0～255，共 256 个数。

但现实中有负数！计算机怎么知道 `1111 1111` 是"255"还是"-1"？

这就需要一套**专门表示负数的规则**。

---

### 🧱 第一步：最朴素的想法——符号位

最直觉的方案：用最高位（最左边那一位）表示正负，0 表示正，1 表示负。

```
+5  →  0000 0101
-5  →  1000 0101（只是把最高位改成1）
```

这叫**原码（Sign-Magnitude）**。

看起来不错，但有两个致命问题：

**问题一：0 有两个表示**
```
+0  →  0000 0000
-0  →  1000 0000
```
同一个数字有两种写法，浪费了一个编码，也让计算变复杂。

**问题二：加法会出错**
```
  0000 0101  (+5)
+ 1000 0101  (-5)
-----------
  1000 1010  ← 这是 -10，不是 0！
```

计算机做加法时不"理解"符号位，只是机械地把每一位相加，原码的加法结果是错的。

这意味着如果用原码，计算机要**为加法和减法写两套不同的电路**，非常麻烦。

---

### 🧱 第二步：反码——过渡方案

**反码（One's Complement）**：正数不变，负数把原码除符号位以外的所有位取反（0变1，1变0）。

```
+5  →  0000 0101（正数不变）
-5  →  1111 1010（把0000 0101除符号位以外全部取反）
```

验证一下 +5 + (-5)：
```
  0000 0101  (+5)
+ 1111 1010  (-5)
-----------
  1111 1111  ← 这是反码的 -0，不是 +0
```

有进步，但 0 还是有两种表示（`0000 0000` 和 `1111 1111`），仍然不够完美。

---

### 🧱 第三步：补码——真正的解决方案

**补码（Two's Complement）**：正数不变，负数 = 反码 + 1。

```
+5  →  0000 0101
-5  →  反码 1111 1010，再加 1 = 1111 1011
```

验证 +5 + (-5)：
```
  0000 0101  (+5)
+ 1111 1011  (-5)
-----------
1 0000 0000  ← 最高位进位溢出，8位内只保留 0000 0000 = 0 ✅
```

完美！结果是 0，而且 0 只有一种表示（`0000 0000`）。

---

### 📊 8位补码对照表（部分）

| 十进制 | 补码（8位） |
|---|---|
| +127 | 0111 1111 |
| +5 | 0000 0101 |
| +1 | 0000 0001 |
| 0 | 0000 0000 |
| -1 | 1111 1111 |
| -5 | 1111 1011 |
| -127 | 1000 0001 |
| -128 | 1000 0000 |

> 🔑 **规律**：最高位是 0 → 正数；最高位是 1 → 负数。
> 8 位补码可以表示 -128 到 +127，共 256 个数，比原码多表示了一个数（-128）。

---

### 🔬 进阶小窗①：为什么补码如此天才？

补码最妙的地方：**减法变成了加法**。

`5 - 3` 等于 `5 + (-3)`，计算机只需要一套加法电路，就能同时处理加法和减法。这大大简化了 CPU 的电路设计。

这也是为什么几乎所有现代计算机都使用补码表示负数——不是规定，是数学上最优雅的选择。

### 🔬 进阶小窗②：整数溢出——一个真实的 Bug

8 位补码最大正数是 127（`0111 1111`）。

如果 127 + 1 会发生什么？
```
  0111 1111  (127)
+ 0000 0001  (1)
-----------
  1000 0000  → 这是 -128！
```

**127 + 1 = -128**，这就是**整数溢出（Integer Overflow）**。

历史上的真实事故：1996年阿丽亚娜5号火箭发射失败，原因之一就是整数溢出——一个64位浮点数被转换成16位整数时超出了范围，导致系统崩溃，火箭自毁，损失5亿美元。

### ⚡ 实用技巧

- **Python**：Python 的整数没有溢出问题，它会自动扩展精度。
- **C/Java**：`int` 是 32 位，范围 -2,147,483,648 到 2,147,483,647。超出就溢出，要小心。
- **快速求负数的补码**：从右往左找到第一个 1，这个 1 和它右边的 0 保持不变，左边的所有位取反。比 "反码+1" 更快。

## 📐 板块二：数学（从基础讲起）

> **今日定位**：今天从零开始讲线性代数的第一块砖——向量是什么。不假设任何先修知识。

**📍 体系定位：** 线性代数 → **【第一课：向量——有方向的数 ← 第 3 期】**

---

### 📌 今日主题：向量是什么？——从"一个数"到"一组数"

### 💡 为什么需要向量？

**普通的数（标量）** 只能描述大小：今天气温 30 度、我走了 5 公里。

但有些东西，光有大小不够：

- 风速：10 米/秒，但是向**哪个方向**吹？
- 力：100 牛顿，但是向**哪个方向**推？
- 位移：走了 5 公里，但是向**哪个方向**走？

这些需要同时描述**大小和方向**的量，就是**向量（Vector）**。

---

### 🧱 向量长什么样？

**最简单的向量：2 维向量**

```
[3, 4]
```

这个向量的意思是：**向右走 3 步，向上走 4 步**。

画在坐标系里，就是从原点 (0,0) 出发，到达点 (3,4) 的一条箭头。

```
  4 | ....→ (3,4)
  3 | ...↗
  2 | ..↗
  1 | .↗
  0 +--------
    0  1  2  3
```

**向量的两个核心属性：**
- **大小（模）**：这条箭头有多长？= √(3² + 4²) = √25 = **5**
- **方向**：箭头指向哪里？

---

### 🧱 向量的基本运算

**① 向量加法：首尾相连**

```
a = [2, 1]   （向右2，向上1）
b = [1, 3]   （向右1，向上3）

a + b = [2+1, 1+3] = [3, 4]
```

直觉：先按 a 走，再按 b 走，终点就是 a+b。

**② 向量数乘：拉伸或压缩**

```
a = [2, 1]
2a = [4, 2]   （方向不变，长度变成2倍）
-a = [-2, -1]  （方向反转，长度不变）
```

**③ 向量减法：a - b = a + (-b)**

```
a - b = [2-1, 1-3] = [1, -2]
```

---

### 📊 从 2 维到 n 维

向量不止 2 维。

**3 维向量**：`[3, 4, 5]` → 在三维空间中的一个方向。

**n 维向量**：`[x₁, x₂, x₃, ..., xₙ]` → 在 n 维空间中的一个方向。

> 🔑 **为什么要关心 n 维？**
>
> 一首歌的音频，可能被表示成一个 1000 维的向量（1000 个频率分量）。
> 一个用户的购物偏好，可能被表示成一个 500 维的向量（500 种商品类别的偏好程度）。
> ChatGPT 处理的每个词，都被表示成一个 1536 维的向量。
>
> 向量是现代 AI 的语言。你看到的所有推荐算法、图像识别、语言模型，底层都是向量的运算。

---

### 🔬 进阶小窗：向量的"点积"——两个向量有多像？

**点积（Dot Product）** 是向量运算中最重要的操作之一：

```
a = [1, 2]
b = [3, 4]
a · b = 1×3 + 2×4 = 3 + 8 = 11
```

计算方法：对应位置相乘，然后加总。

**点积的直觉意义：两个向量有多"同向"。**

- 点积为**正数**：两个向量方向大体相同（夹角小于 90°）
- 点积为 **0**：两个向量互相垂直（完全无关）
- 点积为**负数**：两个向量方向大体相反（夹角大于 90°）

> 💡 **实际应用**：搜索引擎用点积判断"你的搜索词"和"网页内容"有多相关。两者向量的点积越大，越可能是你要找的结果。

### 📌 今日主题：什么是算法？——解决问题的步骤

### 💡 算法其实你每天都在用

**算法**，就是解决某个问题的**一系列明确步骤**。

举个最日常的例子——**早上出门的算法：**

```
第1步：闹钟响了，起床。
第2步：如果还想睡，再睡10分钟，回到第1步。
第3步：刷牙洗脸。
第4步：检查今天的天气。
第5步：如果下雨，拿伞；否则不拿。
第6步：出门。
```

这就是算法：**输入**（闹钟时间、天气）→ **步骤**（一系列操作）→ **输出**（出门状态）。

计算机里的算法，是完全一样的道理——只不过处理的是数字而不是人。

---

### 🧱 算法的三个基本结构

所有算法，不管多复杂，都由这三种结构组成：

**① 顺序（Sequence）**：按顺序一步步执行。
```
先做A，再做B，再做C。
```

**② 判断/分支（Condition）**：根据条件走不同的路。
```
如果下雨 → 拿伞
否则     → 不拿伞
```

**③ 循环（Loop）**：重复执行，直到满足条件为止。
```
还想睡 → 继续睡，检查，还想睡 → 继续睡 ... 直到不想睡为止
```

> 🔑 **记住这三个词**：顺序、判断、循环。世界上所有程序，都是这三种结构的组合。

---

### 🧱 用一个具体例子感受算法：在一排数字中找最大值

**问题**：给你一排数字 `[3, 7, 1, 9, 4, 6]`，找出最大的那个。

**你会怎么做？** 你的大脑是这样的：

```
扫一遍，记住目前见过的最大值。
每看到一个新数，如果它比"目前最大值"更大，就更新。
最后手里的就是答案。
```

把这个过程写成算法步骤：

```
第1步：把"目前最大值"设为第一个数（3）。
第2步：从第二个数开始，逐个查看：
    - 看到 7：7 > 3，更新最大值为 7。
    - 看到 1：1 < 7，不更新。
    - 看到 9：9 > 7，更新最大值为 9。
    - 看到 4：4 < 9，不更新。
    - 看到 6：6 < 9，不更新。
第3步：输出最大值 9。✅
```

这就是一个完整的算法。简单但真实。

---

### 🧱 算法的好坏怎么衡量？

同一个问题可以有很多种算法，怎么判断哪个更好？

**两个维度：**

**① 时间**：需要多少步骤？（步骤越少越好）

刚才找最大值，我们看了 6 个数，执行了 6 步。如果有 100 个数，就需要 100 步。这个算法的步骤数和数据量**成正比**。

**② 空间**：需要记住多少东西？（记忆越少越好）

刚才我们只需要记住"目前最大值"一个数，不管输入多少个数，额外记忆的东西始终只有 1 个。这个算法的额外记忆需求**不随数据量增长**。

> 💡 **下期预告**：我们会正式引入"大 O 记法"——一种用来精确描述"算法需要多少步骤"的数学语言。今天先建立直觉，下期学语言。

---

### 🔬 进阶小窗：算法思维在生活中的应用

**判断一个数是不是偶数：**
```
第1步：用这个数除以 2。
第2步：如果余数是 0，它是偶数；否则是奇数。
```

**在字典里查一个单词（二分法直觉）：**
```
第1步：打开字典中间。
第2步：如果目标单词在前半部分，扔掉后半；否则扔掉前半。
第3步：重复，每次把范围缩小一半。
```

这个查字典方法，比从第一页开始逐页翻快得多——这就是算法效率的本质。下期我们会精确计算它快多少。

## 🏗️ 板块四：数据结构（从基础讲起）

> **今日定位**：数据结构系列重新从零开始。今天先理解"数据结构"这个词是什么意思。

**📍 体系定位：** 数据结构导论 → **【第一课：什么是数据结构？为什么需要它？ ← 第 3 期】**

---

### 📌 今日主题：什么是数据结构？——数据怎么"摆放"很重要

### 💡 从一个生活问题开始

假设你是一个图书馆管理员，有 10000 本书。

**场景 A**：书随机乱放，想找一本书就得一本本找，最坏情况要找 10000 次。

**场景 B**：书按字母顺序排列，配有索引卡片，找一本书只需几步。

**场景 C**：书按类别分区，区内再按字母排，还有电脑检索系统，几秒就能找到。

**数据结构**，就是"如何组织数据"的方案。不同的组织方式，决定了"找数据"、"加数据"、"删数据"有多快。

---

### 🧱 最基础的数据结构：数组

**数组（Array）**，就是把数据排成一排，每个位置有编号（从 0 开始）。

```
位置：  0    1    2    3    4
数据：  5    12   3    8    1
```

**怎么用？**

- 取第 2 个数：直接去位置 2，取出 3。（非常快，1步）
- 找数字 8 在哪：从头开始一个个看，位置 3 是 8。（需要逐个查）
- 在位置 1 插入数字 99：位置 1 及之后的所有数都要往后挪一位，才能腾出空间。（数据越多越慢）

---

### 📊 数组的日常类比

想象一排停车位：

| 车位编号 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 车牌 | 京A1234 | 京B5678 | 空 | 京C9012 | 京D3456 |

- **查询**：告诉我 3 号车位是谁的车 → 直接去看，O(1)，超快。
- **插入**：在 1 号和 2 号之间加一辆车 → 2、3、4 号都要后移，麻烦。
- **删除**：把 1 号车开走 → 留下空洞，或者把后面的车都前移。

这就是数组的特点：**查询极快，增删麻烦**。

---

### 🧱 为什么需要不同的数据结构？

数组对查询友好，但对插入删除不友好。现实中有很多场景：

- **排队系统**：需要频繁在头部删除（叫号）、尾部添加（排队）
- **浏览器历史**：需要"后退"（从最近的记录开始往前取）
- **通讯录**：需要快速按姓名查找
- **地图导航**：需要找两点间的最短路径

每种场景，都有一种数据结构最适合它。这就是为什么数据结构不止一种。

> 🔑 **核心思路**：数据结构不是在背概念，而是在回答"我的数据最常被怎么使用？"然后选最合适的摆法。

---

### 🔬 进阶小窗：计算机怎么存储数组？

数组在计算机内存里，是真正"一排排"连续存放的：

```
内存地址：100  101  102  103  104
数据：      5    12   3    8    1
```

知道了起始地址（100）和每个数据的大小（假设占1格），要找位置 i 的数，只需计算：
**地址 = 起始地址 + i × 每格大小**

这就是为什么数组查询是"1步"完成的——不用搜索，直接算出地址。

但也正因为必须连续存放，插入时才需要移动其他数据。这是数组速度背后的物理原因。

## 📖 板块五：文学

> **上期回顾**：不可靠叙述者——当讲故事的人在撒谎，以及石黑一雄《长日将尽》的自欺之美。
> **今日衔接**：我们看了"谁在讲"，今天看"怎么处理时间"——故事时间 vs 叙述时间。

**📍 体系定位：** 小说叙事技法 → **【叙事时间——快叙、慢叙、省略、停顿 ← 第 3 期】**

---

### 📌 今日主题：叙事时间——小说里的时间不是钟表时间

### 💡 一个有趣的发现

你有没有注意到：有些小说用 50 页描写一个下午，有些小说用一句话写过了 10 年。

这不是作者偷懒或者啰嗦，而是**有意识的叙事选择**——作者在控制读者"感受时间流逝的方式"。

**两种时间：**
- **故事时间（Story Time）**：故事里真实发生了多长时间（3年、一个下午……）
- **叙述时间（Discourse Time）**：作者用了多少篇幅来写（10页、1句话……）

这两者的关系，就是叙事时间控制的核心。

---

### 📊 四种叙事时间模式

**① 概述（Summary）——快叙**

用比故事时间短得多的篇幅概括大段时间。

> *"接下来的三年，她一直在等他。"*

一句话写了三年。常用于：过渡、交代背景、不重要的时间段。

---

**② 场景（Scene）——等速叙述**

叙述时间 ≈ 故事时间。用对话和细节完整呈现一个场景，读者感觉像在"实时观看"。

> *"你为什么迟到了？"他推开门问。*
> *"路上堵车。"她没看他，径直走向窗边。*

这一段大概发生了 30 秒，读者也花了 30 秒读它。多用于：关键冲突、情感高潮、性格揭示。

---

**③ 停顿（Pause）——慢叙**

叙述时间 >> 故事时间。故事中的时间"冻住了"，作者插入大量描写或思考。

> *窗外的树叶在光里静止着。她想到上一次见他，是七月的傍晚，他的手放在她肩膀上，那种重量她一直记得，像一枚硬币压在心口。*

故事时间几乎是零（主角只是站在窗边），但叙述用了很长篇幅。多用于：刻画内心、渲染氛围、意识流片段。

---

**④ 省略（Ellipsis）——跳过**

某段时间完全不写，直接跳过。

> *"三年后，她回到了这个城市。"*

三年发生的一切，作者选择跳过，直接跳到三年后。多用于：跳过不重要的时间段，或刻意制造"留白"。

---

### 🔬 进阶小窗①：为什么时间控制这么重要？

**时间节奏 = 情感节奏。**

作者用"慢"来放大重要时刻，用"快"来压缩过渡。读者在慢叙里感受细节和情绪，在快叙里感受时间流逝和宿命感。

托尔斯泰《安娜·卡列尼娜》里，安娜赴死的那一刻被用了整整几页来描写（极度慢叙），而之前漫长的婚姻生活往往几句话带过。这种节奏上的不对称，本身就是在说"哪些时刻最重要"。

### 🔬 进阶小窗②：意识流与叙事时间

上期学的意识流，就是极端的"慢叙"——把一瞬间的内心展开成大量文字。《尤利西斯》全书只写了都柏林的一天，却用了 700 多页。故事时间/叙述时间的比值低得惊人，但正是这种极度慢叙，让读者进入了人物意识的最深处。

## 🏛️ 板块六：社会学

> **上期回顾**：社会流动性——阶层电梯正在变慢，教育资本化是重要原因。
> **今日衔接**：流动性涉及"阶层"，而划定阶层的方式之一是性别——今天看性别与社会建构。

**📍 体系定位：** 社会学分层理论 → **【性别与社会建构——性别是天生的还是被塑造的？ ← 第 3 期】**

---

### 📌 今日主题：性别是天生的还是被塑造的？

### 💡 先区分两个词

**生理性别（Sex）**：生物学意义上的，由染色体、激素、生殖器官决定。

**社会性别（Gender）**：社会和文化赋予的，关于"男人应该怎样"、"女人应该怎样"的期望和规范。

社会学关注的核心是：我们认为"自然而然"的很多性别行为，其实是**被社会建构出来的**。

---

### 🔍 几个颠覆直觉的历史案例

**① 粉色原来是男孩的颜色**
20 世纪之前，粉色被认为是热情有力的颜色，更适合男孩；蓝色柔和安静，更适合女孩。这种对应在 1940 年代才被彻底反转——完全是服装工业的市场决策，不是"天生"的。

**② 女性"天生"不擅数学？**
多项跨文化研究发现，在性别平等程度高的国家（如芬兰、冰岛），男女在数学成绩上几乎没有差异；而在性别不平等程度高的地区，差异才会出现。这强烈暗示所谓"天生差异"，很大程度上来自社会期待的内化。

**③ 哭泣是"女性特质"？**
在许多文化中，男性被教导"男儿有泪不轻弹"。但婴儿时期，男女哭泣频率几乎相同；差异是后天社会化的结果。

---

### 🔬 进阶小窗①：波伏娃的洞见

> *"女人不是天生的，而是后天形成的。"——西蒙娜·德·波伏娃，《第二性》*

波伏娃（1949年）是最早系统论述"社会性别"的哲学家之一。她的核心论点：女性的很多特质（温柔、顺从、自我牺牲）不是天生的生物本性，而是在父权社会结构中被反复强化和内化的结果。

这不是说"男女没有任何生理差异"，而是说：生理差异远没有我们以为的那么能解释行为差异，大部分行为差异来自社会化过程。

### 🔬 进阶小窗②：刻板印象威胁（Stereotype Threat）

心理学家 Claude Steele 的实验（1995年）：告诉一组女生"这个数学测试女生通常比男生差"，另一组不说。结果：听到提示的那组，成绩显著下降。

**仅仅听到关于自己群体的负面刻板印象，就足以影响实际表现。** 这叫"刻板印象威胁"，它解释了为什么某些群体在某些领域的"表现差距"，不需要用天生能力来解释。

### 🔬 进阶小窗③：结构性视角

社会学不只看个人态度，更看**制度结构**：
- 产假/陪产假的比例差异，强化了"女性是主要照顾者"的社会角色
- 职场的"母性惩罚"现象：生育后女性薪资下降，男性薪资反而上升（"父性奖励"）
- 这些不是个人偏见，而是制度在系统性地再生产性别不平等

## 💰 板块七：会计

> **上期回顾**：T字账户与借贷记账法——每笔分录借贷必须平衡。
> **今日衔接**：东西放在那里，时间一长会磨损——固定资产怎么反映这种"价值消耗"？

**📍 体系定位：** 会计基础 → 资产处理 → **【固定资产折旧——资产如何"消耗" ← 第 3 期】**

---

### 📌 今日主题：折旧——东西用旧了，账上怎么记？

### 💡 为什么需要折旧？

你花 10 万买了一台机器，用 10 年后报废。

如果你把 10 万全部记在购买那年的费用里，第一年账面亏损，后面 9 年账面上好像这台机器"免费用"——这不准确，也不公平。

**折旧（Depreciation）** 的思路是：把这台机器的 10 万成本，**按使用年限摊分到每一年**，每年记一点费用，匹配这台机器每年带来的收益。

这就是会计"配比原则"——费用应该与产生这个费用的收益在同一期间确认。

---

### 🧱 最常用的折旧方法：直线法

**直线法（Straight-Line Method）**：每年折旧金额相同。

**公式：**
```
每年折旧额 = (原值 - 残值) ÷ 使用年限
```

**举例：**
- 机器原值：10 万元
- 预计使用：5 年
- 5 年后残值：1 万元（卖废铁能值的钱）

```
每年折旧额 = (10 - 1) ÷ 5 = 1.8 万元/年
```

**每年的会计分录：**
```
借：折旧费用  1.8万     （费用增加）
贷：累计折旧  1.8万     （资产账面价值减少）
```

**5年后账面价值：**
```
账面价值 = 原值 - 累计折旧 = 10 - 9 = 1万 = 残值 ✅
```

---

### 📊 直线法折旧表

| 年份 | 年初账面价值 | 折旧额 | 年末账面价值 |
|---|---|---|---|
| 第1年 | 10万 | 1.8万 | 8.2万 |
| 第2年 | 8.2万 | 1.8万 | 6.4万 |
| 第3年 | 6.4万 | 1.8万 | 4.6万 |
| 第4年 | 4.6万 | 1.8万 | 2.8万 |
| 第5年 | 2.8万 | 1.8万 | 1.0万 |

---

### 🔬 进阶小窗①：加速折旧法——资产贬值往往不是匀速的

直线法简单，但不总是符合实际。很多资产在前几年使用多、价值损耗大，后几年少用、损耗小。

**双倍余额递减法（Double Declining Balance）**：每年折旧额 = 年初账面价值 × (2 ÷ 使用年限)

还是上面的例子（忽略残值简化计算）：
```
折旧率 = 2 ÷ 5 = 40%
第1年：10万 × 40% = 4万
第2年：6万 × 40% = 2.4万
第3年：3.6万 × 40% = 1.44万
……
```

前几年折旧多，后几年少——更能反映科技设备等"越用越贬值快"资产的真实状况。

### 🔬 进阶小窗②：折旧 vs 摊销

**折旧（Depreciation）**：针对**有形资产**（机器、车辆、建筑）的价值消耗。

**摊销（Amortization）**：针对**无形资产**（专利、软件、商标）的价值消耗。原理一样，只是适用对象不同。

### 🔬 进阶小窗③：折旧与税务筹划

税法对折旧年限有规定（通常比会计准则允许的更短），企业可以合法地"加速折旧"——早年多记费用，早年少交税。这不是逃税，而是税务筹划。资金有时间价值，早年少交的税在后年再补上，相当于得到了一笔无息贷款。

> **今日衔接**：价格弹性是个人决策，今天上升到多人互动——博弈论的最基础概念。

**📍 体系定位：** 微观经济学 → 策略互动 → **【博弈论入门——囚徒困境 ← 第 3 期】**

---

### 📌 今日主题：博弈论入门——当你的最优选择取决于别人怎么选

### 💡 什么是博弈论？

之前讲的经济学，主要是"一个人面对市场做决策"——我买不买这瓶水，取决于价格和我的需求，跟别人没关系。

但很多现实决策中，**你的最优选择取决于别人怎么选**：

- 要不要降价促销？取决于竞争对手怎么做。
- 要不要军备扩张？取决于对手怎么做。
- 要不要在拥挤的路上加塞？取决于别人要不要让你。

**博弈论（Game Theory）** 就是研究这类"策略互动"的数学工具。

---

### 🧱 最著名的案例：囚徒困境

两个嫌疑人 A 和 B 被分开审讯，无法沟通。检察官给每人两个选择：**沉默（合作）** 或 **坦白（背叛）**。

**规则：**

| | B 沉默 | B 坦白 |
|---|---|---|
| **A 沉默** | A判1年，B判1年 | A判10年，B释放 |
| **A 坦白** | A释放，B判10年 | A判5年，B判5年 |

**从 A 的角度分析：**

- 如果 B 沉默：A 坦白 → 释放（比沉默的1年好）✅
- 如果 B 坦白：A 坦白 → 5年（比沉默的10年好）✅

**结论：不管 B 怎么选，A 坦白都是更好的选择。**

B 的分析完全对称，结论相同。

所以两人都会坦白，各判 5 年。

但如果两人都沉默，各只判 1 年——**这个结果对两人都更好，却无法实现。**

---

### 🔑 囚徒困境的核心洞见

**个人理性 ≠ 集体最优。**

每个人从自身利益出发做出了"理性"决策，但集体结果却是次优的。

这个模型解释了大量现实现象：

- **军备竞赛**：两国都不想军备扩张（代价高），但都担心对方扩张自己不扩，所以最终都扩。
- **价格战**：两家公司都不想降价（利润低），但都怕对方降价抢客户，所以最终都降。
- **公共卫生**：每个人都不想打疫苗（有风险），但如果所有人这样想，群体免疫就实现不了。
- **过度捕鱼**：每条渔船都想多捕，但集体的结果是鱼类资源耗竭。

---

### 🔬 进阶小窗①：纳什均衡

**纳什均衡（Nash Equilibrium）**：在这种状态下，**没有人能通过单方面改变自己的策略来得到更好的结果**。

囚徒困境中，"双方都坦白"就是纳什均衡——A 在 B 坦白的情况下，改成沉默会更差；B 同理。所以没有人会单方面改变。

纳什均衡不一定是最优结果（囚徒困境里"双方沉默"对集体更好），但它是**稳定的状态**——没有人有动机单独改变。

约翰·纳什（电影《美丽心灵》的主角）因此获得1994年诺贝尔经济学奖。

### 🔬 进阶小窗②：重复博弈与合作的出现

囚徒困境的悲剧，发生在**一次性博弈**中。

如果同样的博弈**重复进行很多次**，情况就不同了——今天背叛对方，明天对方会报复，长期来看合作往往是更优策略。

这解释了为什么长期合作关系（朋友、商业伙伴、国际条约）中，合作比背叛更常见：因为双方都知道游戏会继续，声誉和报复机制让"坦白"的短期收益失去了吸引力。

**为什么读**：与本期经济学（博弈论）形成深度呼应。芒格的核心思维工具之一就是博弈论，他把它与心理学、物理学、生物学等学科一起，构建成"多元思维模型"。

**内容概要**：巴菲特的黄金搭档查理·芒格的演讲和思想精华。核心理念：要真正理解一件事，需要从多个学科的视角来看它（"跨学科思维模型"）。内容涵盖如何做决策、如何避免认知偏误、如何看待复利。

**如何阅读**：不需要线性阅读，随机翻开任何一页都有收获。第一部分"芒格的生活、学习与决策"是精华，建议优先读。

> *"获得智慧的第一条规则，就是别愚弄自己——而你是最容易被自己愚弄的人。"*

### ④ 写作与表达 · 《故事》

**作者**：罗伯特·麦基　**豆瓣评分**：9.1　`/ 剧本写作 / 故事结构 / 叙事理论`

**为什么读**：与本期文学板块（叙事时间）直接衔接。麦基系统分析了故事结构，包括时间节奏、场景设计、冲突构建。虽然以影视剧本为例，但原理适用于所有叙事写作。

**内容概要**：好莱坞编剧圣经。麦基用"价值转变"定义场景（每个场景结束时，主人公的处境在某个维度发生了正负转变），用"故事脊椎"串联全片。读完你会用全新的眼光看每一部电影。

**如何阅读**：建议边读边对照一部你熟悉的电影分析。第二部分"故事的要素"是核心，其余可选读。

> *"故事是生命的比喻。"*

### ⑤ 摄影与审美 · 《亨利·卡蒂埃-布列松：二十世纪的眼睛》

**作者**：克莱芒·谢鲁　**豆瓣评分**：8.9　`/ 摄影史 / 人文摄影 / 大师传记`

**为什么读**：与本期摄影板块（对角线构图与决定性瞬间）直接关联。布列松是"决定性瞬间"理论的创立者，理解他的创作思路，是理解现代摄影美学的基础。

**内容概要**：布列松的生平与摄影哲学，配有大量代表作品。他的核心理念：好的照片是"形式与内容在某一瞬间的完美结合"，这一刻稍纵即逝，摄影师必须提前准备好构图，等待生命流过。

**如何阅读**：图文并重，先看图再读文字说明，感受布列松的构图逻辑，然后在生活中寻找类似时刻。

> *"摄影对我来说，是在一秒的几分之一里，同时认知到某一事件的重要性，以及能精确表达这一事件的形式的精确组织。"*

## 🎨 板块十：写作与摄影 · 每日一练

### ✍️ 写作灵感

#### 今日主题：写一个"误解"

**练习题**：用 150～200 字，描写一次误解——你误解了别人，或别人误解了你。不要解释误解"后来是怎么消除的"，只写那个误解存在的时刻。

**重点**：让读者同时看到两个视角——误解者的"合理推断"，以及被误解者的"真实状态"，但不要用"其实"、"事实上"这类词直接挑明。

---

> 💡 **今日技巧：用"空白"制造张力**
>
> 最好的小说不会把所有信息都给读者，而是"给一半，藏一半"。
>
> 读者在填补空白的过程中，会产生真实的情感卷入——这比作者直接告诉读者"你应该感到悲伤"有效一百倍。
>
> 今天的练习，就是训练"留白"：写出误解，但不急着解释，让读者自己感受那种错位。

---

### 📷 摄影眼训练

#### 今日任务：拍一张"孤独感"

不要拍字面意义上"一个人坐在那里"的照片——那太直接了。

尝试用**间接手法**表达孤独：
- 一把空椅子旁边的满椅子
- 一盏还亮着的灯，外面天已经大亮
- 一双筷子摆在空碗旁边
- 角落里的雨伞，旁边没有人

**要求**：不出现人物，但让看到照片的人感受到"有人曾经在这里"或"有人缺席"。

---

#### 🎯 今日构图重点：框架构图

**框架构图（Framing）**：用画面中已有的元素（门框、窗框、树枝、拱门）来"框住"你的主体。

**为什么有效：**
- 引导观看者视线聚焦到主体
- 增加画面的层次感和纵深感
- 让主体产生"被观看"的戏剧感

**今日练习**：找一个窗口、门口或拱形结构，把主体放在框架内拍摄。注意框架本身不要太抢眼，它是引导，不是主角。
